Este es la inicialización del proyecto de Seminario de Tesis II.
En este proyecto realizaremos las pruebas en base al cronograma de entregables e hitos por semana, en un lapso de 17 semanas.

La finalidad de este proyecto es realizar el entrenamiento de modelos y  comprobar el desempeño de estos así como usar XGBoost y diferentes modelos así como comprobar su eficacia y explicabilidad del porque de la "DESERCION DE ESTUDIANTES" a través del estudio del dataset uc=047 en base a datos socioeconomicos.

El producto final es el cruce de diferentes modelos de machine learning, su desempeño registrado y explicado a través de SHAP, logrando así tener una herramienta para predecir la deserción estudiantil de forma probada para luego reproducirlo con datos reales propios de la universidad nacional de juliaca corroborando con sus datos reales de estudiantes en estado de deserción.
